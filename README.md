# Delta

Postgres/MySQL/Mongo CDC engine that streams changes to Kafka, Pulsar, or webhooks with low-latency ordering.

## Tagline
Change data capture, <span class='grad-text'>real-time

## Features
- AI-powered data streaming workflows
- 200+ first-party connectors
- Sub-second execution with warm pools
- Sandboxed runtime with audit trails
- Per-project encrypted secret vault
- Multi-region deployment for GDPR
- Powered by MiMo-Series, Claude-Series, DeepSeek-Series

## Quickstart
```bash
curl -fsSL delta-cdc-stream.dev/install | sh
delta init --model mimo-v2.5-pro
```
